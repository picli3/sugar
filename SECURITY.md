# Security policy / Política de seguridad

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: **[Report a vulnerability](https://github.com/picli3/sugar/security/advisories/new)**. Reports are visible only to the maintainer (Maykol Rey).

- Do not open public issues, pull requests or discussions with vulnerability details.
- Do not run destructive, denial-of-service or data-modifying tests against the public installation (`sugar.maykolrey.com`), and do not access accounts or data that are not yours. Use a local installation (see `README.md`) to reproduce issues.
- Include the affected version or commit, steps to reproduce and the impact you observed.

There is no bug bounty. Response times are best effort; this project does not offer contractual guarantees.

## Informar de una vulnerabilidad

Informa de forma privada mediante GitHub: **[Report a vulnerability](https://github.com/picli3/sugar/security/advisories/new)**. Sólo el responsable (Maykol Rey) ve los reportes.

- No abras issues, pull requests ni discusiones públicas con detalles de la vulnerabilidad.
- No hagas pruebas destructivas, de denegación de servicio ni que modifiquen datos contra la instalación pública (`sugar.maykolrey.com`), ni accedas a cuentas o datos ajenos. Reproduce los problemas en una instalación local (ver `README.md`).
- Incluye la versión o commit afectado, los pasos para reproducirlo y el impacto observado.

No hay programa de recompensas. La respuesta se da en la medida de lo posible, sin garantías contractuales.

For other help: maykolrey@gmail.com. How Sugar handles data is described in the app at `/?privacy`.
